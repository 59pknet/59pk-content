本文用四步讲清 SSTap 的完整用法：下载安装、添加 SOCKS5 代理、选代理模式、点连接并核对，再讲设置里的 DNS、游戏规则模式和常见问题。照着做，第一次用也能连上。

## SSTap 是什么

SSTap（SOCKSTap）是一款免费的 Windows 代理工具。它在系统里装一块虚拟网卡，在网络层接管整台电脑的流量，把 TCP 和 UDP 流量按规则转发到你配好的 HTTP、SOCKS4、SOCKS5 或 Shadowsocks 代理上。装好之后不用给每个游戏、每个程序单独设代理，选好线路和模式，点一下连接，整台机器就按规则走代理。

先说清楚三点：第一，SSTap 只支持 Windows，没有 macOS 和手机版；第二，SSTap 本身不带任何线路，线路要另外通过正规渠道获取，本文只讲怎么把线路配进去，不提供线路；第三，SSTap 已经停止开发，最后一个正式版是 1.1.0.1（2017 年 11 月），原官网 sockscap64.com 目前已无法访问，安装包只能从可信的镜像渠道获取，下载后先杀毒，警惕捆绑改包。

## 准备工作

开始之前准备好三样东西：

1. 一台 Windows 电脑（Win7/Win10/Win11 都能用，Win11 建议先装好 VC++ 2015-2022 运行库，否则可能装不上或打不开）。
2. 一条 SOCKS5 代理线路：地址（IP 或域名）、端口、账号、密码，四项缺一不可。
3. 管理员权限：安装和运行都要右键“以管理员身份运行”，否则虚拟网卡装不上、本地代理服务起不来。

另外注意：先退出电脑上其他 VPN、加速器、代理软件，避免端口冲突和流量互相抢。

## 第 1 步：下载安装

1. 获取安装包 `SSTap-beta-setup-1.1.0.1.exe`（可信镜像渠道，文件约十几 MB）。
2. 右键安装包，选“以管理员身份运行”。
3. 按向导一路点“下一步”，安装路径保持默认即可。
4. 安装中途 Windows 会弹“您想安装这个设备软件吗？”，这是 SSTap 的虚拟网卡（TAP）驱动，点“安装”。这一步必须允许，否则 SSTap 装完也连不上。
5. 装完后先不要急着点“运行”。先在桌面找到 SSTap 图标，右键“以管理员身份运行”。

> Win11 用户如果装完打不开或一打开就报错，先装 Microsoft Visual C++ 2015-2022 运行库，再重新运行 SSTap。

## 第 2 步：认识主界面

第一次打开，看到的是这样的主界面：

![图片[2]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117112318807.png/59pk)

主界面上一共就几个东西，认一遍：

- **代理**：下拉框，选当前要用的那条线路。后面四个小图标依次是：添加代理（+）、删除代理（−）、编辑代理、测试代理（闪电）。
- **模式**：下拉框，选流量怎么分流，决定哪些走代理、哪些直连。这一步最关键，后面第 3 步细讲。
- **连接**：蓝色大按钮。点一下开始连接，点一下断开。
- **底部状态栏**：流量统计、实时速度、连接数，左下角显示当前状态（未连接时显示“已断开！”）。
- 模式下拉框右边那个小图标（上图红箭头指的位置）是模式管理入口，用来新建、修改代理模式，基础用法用不到。

## 第 3 步：添加 SOCKS5 代理

1. 点“代理”下拉框旁边的 **+** 号，弹出菜单：

![图片[3]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117112340220.png/59pk)

2. 选第一项“添加 HTTP/SOCKS4/SOCKS5 代理…”，打开添加窗口。
3. 按下面这样填（以 SOCKS5 为例）：
   - 代理类型：选 **SOCKS5**。
   - 代理地址：填线路给你的 IP 或域名。
   - 代理端口：填线路给你的端口。
   - 账号、密码：有就填，没有就留空。
4. 点“测试”，SSTap 会跑一轮检测，弹出测试日志：

![图片[4]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117112409913.png/59pk)

测试日志里要看到两行绿色的 **Passed!** 才算通过：

- `TCP transmission...Passed!`：TCP 能通。
- `UDP relay...Passed!`：UDP 转发能通。玩游戏要走 UDP，这一行不过，游戏里会掉线或连不上。
- 下面还会显示 `Latency : 47 ms`，这是这条线路的延迟，数字越小越好。

5. 测试通过后点“保存”，这条线路就出现在“代理”下拉框里，旁边还会显示它的延迟。以后想换线路，直接在下拉框里选；想重新测延迟，点线路后面的闪电图标。

> 测试不通过先别保存：先检查地址、端口、账号密码有没有抄错，再确认线路本身是不是过期或停用。换一条线路再测一次。

## 第 4 步：选择代理模式

模式决定哪些流量走代理、哪些直连，选错了会出现“连上了但游戏还是卡”“国内网站也变慢”这类问题。三种最常用的模式：

![图片[5]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117142318543.webp/59pk)


| 模式 | 国内网站 / 国内游戏 | 国外网站 / 国外游戏 | 适合谁 |
| --- | --- | --- | --- |
| 全局 – 内置规则 | 走代理 | 走代理 | 全部流量都要走代理时 |
| 不代理中国IP | 直连 | 走代理 | 国内玩外服，新手首选 |
| 仅代理中国IP | 走代理 | 直连 | 海外玩国服 |

新手建议这样选：

- **人在国内、玩外服游戏**：选“不代理中国IP”。国内网站和国服游戏继续直连，速度不受影响；只有访问国外站点、玩外服游戏时才走代理。
- **人在海外、玩国服游戏**：选“仅代理中国IP”。只有国内的流量走代理，其他流量直连。
- **不知道该选哪个**：先选“不代理中国IP”，连上、能玩、国内网站也正常，就是对的。

除了这三个内置模式，下拉框里还会看到一串游戏名字（PUBG、CS:GO、守望先锋、GTA V 等），那是针对单个游戏的规则模式：只把这个游戏的流量走代理，其他程序全部直连。想只加速某一个游戏、其余程序不受影响时再用，见进阶第 2 节。

![图片[6]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117141831928.png/59pk)

## 第 5 步：连接并核对

1. 在“代理”下拉框里选中刚加好的线路。
2. 在“模式”下拉框里选好模式。
3. 点蓝色“连接”按钮。按钮文字变成“断开连接”，左下角状态改变，底部状态栏的实时速度开始有数字，就说明已经连上了。
4. 核对出口 IP：打开浏览器，访问 IP 查询站（例如 ip138.com 或 IP.cn），看页面上显示的 IP 是不是已经变成代理线路的出口 IP。如果显示的还是你自己的宽带 IP，说明没接管成功，回到第 4 步检查模式，或看常见问题第 1 条。
5. 进游戏试一把：能正常登录、延迟稳定，就可以用了。

不用的时候点“断开连接”即可。SSTap 退出后流量恢复直连，不用改任何系统设置。

## 进阶 1：设置里的 DNS

平时不用动 DNS。只有连上之后出现“网页打不开”“域名解析很慢”“游戏能进但商店加载不出来”时，再改：

![图片[7]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117142358407.webp/59pk)

1. 点主界面右下角的齿轮图标，进“设置…”。
2. 找到“预选 DNS”，选“自定义”，首选 DNS 填 `1.1.1.1`，备用 DNS 填 `1.0.0.1`。
3. 勾上“代理 DNS 服务器”，让域名解析也走代理。
4. 确定，断开再重新连接一次，让新设置生效。

> 如果改完反而更慢，就把“预选 DNS”改回默认，取消“代理 DNS 服务器”，断开重连。

## 进阶 2：只加速某一个游戏（游戏规则模式）

SSTap 支持按游戏单独配规则：只把某一个游戏的流量走代理，其他程序全部直连。做法是往 SSTap 的规则目录里放一个 `.rules` 文件（规则文件），文件里写这个游戏的服务器 IP 段，模式下拉框里就会多出这个游戏的选项。

自己写规则文件要懂 CIDR 写法（例如单个 IP 写 `/32`，同一网段写 `.0/24`），第一次用建议直接用现成的游戏规则：网上有玩家维护的 SSTap 规则合集，按游戏名找对应的 `.rules` 文件，下载后放进 SSTap 安装目录的规则文件夹，重启 SSTap，模式下拉框里就有了。规则文件只认服务器 IP，不认账号密码，来源要可靠。

> 有些游戏用严格 NAT 或 P2P 联机（例如某些主机游戏的联机模式），SSTap 解决不了，换了规则、换了线路也进不去，这是工具本身的限制，不是设置问题。

## 进阶 3：SS / SSR 订阅（一句话）

除了手动加 SOCKS5，SSTap 也支持 Shadowsocks / SSR：点托盘菜单里的“SSR 订阅”，填订阅地址可以批量拉取节点；也可以点“添加 SS/SSR 代理…”手动加一条。本教程以 SOCKS5 为主，SS/SSR 的添加和测试流程与第 3 步相同。

## 常见问题

**1. 点连接提示“本地代理服务启动失败”**

最常见的原因是端口被占或权限不够。先退出其他 VPN、加速器、代理软件，再右键“以管理员身份运行”SSTap；还不行就重启电脑再试。Win11 用户确认已装 VC++ 2015-2022 运行库。

**2. 连上了，但游戏进不去或一进就掉线**

先看第 3 步的测试日志：UDP relay 必须 Passed，UDP 不通游戏基本玩不了。再看模式有没有选错（国内玩外服却选了“仅代理中国IP”，流量根本没走代理）。最后换一条延迟更低的线路试试。

**3. 连上后国内网站变慢、视频卡**

模式选错了：你现在用的可能是“全局”，所有流量都走了代理。改成“不代理中国IP”，国内流量直连就好了。

**4. 延迟忽高忽低、动不动断线**

先点线路后面的闪电图标重测延迟，换一条延迟低且稳定的线路；再检查是不是同时开了其他代理软件抢流量；高峰期线路本身拥挤也会这样，换个时间段或换条线路。

**5. 杀毒软件报毒、安装包被删**

SSTap 是 2017 年停更的老软件，部分杀软会误报。先确认安装包来自可信镜像、文件没被改过，再把 SSTap 加入杀软白名单。来源不明的安装包不要装，不要从不明链接下载。

**6. SSTap 和 Proxifier 该用哪个**

只想给游戏加速、一台电脑一个用途，用 SSTap：三步就能用，模式按游戏配。想按程序精细控制（例如只让 A 软件走代理、B 软件直连、C 软件走另一条线），用 Proxifier 的按进程规则。两者不冲突，但不要同时开着接管同一台机器。

## 收尾核对清单

做完这篇教程，确认下面几项都对得上：

- SSTap 以管理员身份运行，虚拟网卡驱动已安装
- SOCKS5 线路已添加，测试日志里 TCP 和 UDP 都是 Passed
- 模式选对了：国内玩外服选“不代理中国IP”，海外玩国服选“仅代理中国IP”
- 点连接后按钮变成“断开连接”，状态栏有实时速度
- IP 查询站显示的出口 IP 已经是代理线路的 IP
- 游戏能正常登录，延迟稳定；国内网站速度正常

## 常见问题（FAQ）

**Q1：SSTap 是免费的吗？**

是。SSTap 本身免费，软件不带线路。线路要另外通过正规渠道获取，线路本身可能收费，费用与 SSTap 无关。

**Q2：SSTap 支持哪些系统？**

只支持 Windows（Win7/Win10/Win11）。没有 macOS 版，也没有手机版。Win11 建议先装 VC++ 2015-2022 运行库。

**Q3：SSTap 现在还能用吗？它不是停更了吗？**

能用。SSTap 最后一个正式版是 1.1.0.1，2017 年 11 月停止开发，但软件本身的功能（虚拟网卡接管、SOCKS5 转发、模式分流）至今仍可正常使用。原官网已无法访问，安装包要从可信镜像获取。

**Q4：测试时 UDP relay 失败怎么办？**

UDP 失败一般是线路不支持 UDP 转发，或端口、账号密码填错。先核对四项信息，换一条明确支持 UDP 的线路再测。UDP 不通也能上网，但游戏基本玩不了。

**Q5：新手该选哪个模式？**

人在国内玩外服游戏，选“不代理中国IP”；人在海外玩国服游戏，选“仅代理中国IP”。不知道选哪个时，先选“不代理中国IP”。

**Q6：SSTap 会影响国内网站的速度吗？**

看模式。选“不代理中国IP”时国内流量直连，不受影响；选“全局”时全部流量走代理，国内网站也会变慢。觉得国内网站变慢了，先检查模式。
