很多人一上来就问静态 IP 怎么设。其实第一步不是填数字，是先分清你要固定的是哪一个。静态 IP 有两种：局域网静态 IP 和公网静态 IP，方法不一样，找谁办不一样，要不要花钱也不一样。弄混了，照着教程设半天，设完发现根本不是自己要的。

## 先分清：内网固定，还是出口固定

局域网静态 IP 是内网地址，一般是 192.168.x.x 开头。它的用处在家里：给 NAS 一个固定地址，端口转发指到一台不会变的机器，或者家里局域网里的设备互相认得路。这个自己在路由器上就能定，不用找运营商。

公网静态 IP 是外网出口的地址固定不变。家里普通宽带拨号，拿到的公网 IP 都是动态的，过段时间就会变。想要出口固定，家里宽带基本不给。

一句话区分：内网固定是让家里设备之间互相找得到；出口固定是让外网每次都找到同一个你。模拟器多开的时候，一个窗口绑一个固定 IP，用的就是内网固定这套思路，[老鱼加速器的单窗口单 IP 就是这么配的](https://www.59pk.net/135.html)。

## 内网固定，首选路由器里做地址保留

内网固定有两种做法，首选路由器里的 DHCP 地址保留。电脑、手机这边什么都不用改，继续自动获取 IP，由路由器每次给指定设备分配同一个内网地址。好处是以后换设备、重装系统，也不用重新再配置一遍，而且不容易 IP 冲突。

1. 浏览器打开路由器后台，常见地址是 192.168.1.1 或者 192.168.0.1，登录账号密码一般印在路由器底部贴纸上面。 2. 在后台找到 DHCP 服务器或者 LAN 设置，菜单名字各家路由器略有区别，叫静态地址保留、DHCP 地址预约、ARP 绑定的都有。 3. 新增一条记录：填入设备的 MAC 物理地址，再填你想固定的内网 IP，举个例子 192.168.1.120，注意这个 IP 要避开路由器 DHCP 自动分配的地址段。 4. 保存设置，设备把 WiFi 或者网线断开重连，就会拿到固定内网 IP 了。

MAC 地址在 Windows 上查很方便：打开 CMD，输入 ipconfig /all，找到正在使用网卡对应的物理地址就是 MAC。

设完先别急着收工，[查一下当前 IP 对不对得上](https://www.59pk.net/ipcheck)，拿到的地址和你填的一致，才算真固定了。

## 也可以在电脑上直接改，但先抄好网关

不想进路由器后台，也可以在 Windows 电脑上直接手动设置静态 IP，Win10、Win11 操作差不多：

1. 快捷键 Win+I 打开系统设置，进入网络和 Internet，找到以太网或者 WiFi，点开更改适配器选项。 2. 右键你正在上网的网卡，以太网就是网线，WLAN 就是无线网，选择属性，双击 Internet 协议版本 4(TCP/IPv4)。 3. 勾选使用下面的 IP 地址，照着填写：IP 地址 192.168.1.120，要和路由器同一个网段，别跟家里其他设备撞 IP；子网掩码 255.255.255.0；默认网关填路由器后台地址，大多是 192.168.1.1；首选 DNS 114.114.114.114，备用 DNS 8.8.8.8。全部点确定保存，网卡禁用再重新启用，设置就生效。

手动填之前，先打开 CMD 执行 ipconfig，把网关、子网掩码抄下来再填。手动设置的 IP，一定不能落在路由器 DHCP 自动分配的区间里面，不然会出现 IP 冲突，网络时好时坏，时不时断网。

macOS 也一样：打开系统设置→网络，选中当前在用的网络，点详细信息，切换到 TCP/IP。IPv4 配置选择手动，依次填好 IP 地址、子网掩码、路由器也就是网关，再切到 DNS 栏目填上 DNS 服务器，保存应用即可。

电脑上直接改适合只有一台设备、临时固定。路由器地址保留更省事，设备换了、系统重装了都不用再管。

## 想要出口 IP 固定，家里宽带基本没戏

普通个人家庭宽带，运营商一般不会给固定公网静态 IP。想要这个，需要办理政企互联网专线，大多需要营业执照，每月资费比较高。运营商会给到完整 IP、网关、子网掩码这一套参数，直接填进路由器 WAN 口，选择静态 IP 模式使用。

这里一定要区分开，局域网静态 IP ≠ 公网出口静态 IP，二者不是一回事。代理 IP 里常说的独享静态 IP、动态住宅 IP，讲的也是出口变不变，但那是代理线路的用法，[申请的时候挑类型是另一个话题](https://www.59pk.net/221.html)。

## 设完出问题，先查这三处

网关或者 DNS 填错，内网设备互相访问没问题，但就是上不了外网。先回头核对默认网关和 DNS 是不是抄错了，网关一般就是路由器后台地址。

IP 冲突，网络时好时坏，断断续续。查一下手动填的地址是不是落进了 DHCP 自动分配的区间，或者家里另一台设备已经占了同一个地址，换一个池子外的地址重新设。

电脑手动设置静态 IP 之后，去连别的 WiFi 环境，直接无法上网。遇到这种情况，把 IPv4 改回自动获取 DHCP，立刻就能恢复正常。出门前记得改回来，不然到了新地方还是上不了网。

说到底，静态 IP 没什么难的，难的是动手前先分清。内网固定在路由器里做地址保留最稳，换设备、重装系统都不用再管；出口固定得找运营商办专线，家里宽带给不了。设完查一遍，拿到的地址对得上，才算完。
