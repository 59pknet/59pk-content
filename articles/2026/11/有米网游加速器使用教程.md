如果你在多开模拟器，想让每个窗口走不同的 IP，或者想让某个游戏单独走代理、别的程序一点不受影响，有米网游加速器就是干这个的。它不接管整台电脑，只按进程分配线路：你把游戏、模拟器加进来，再给每个进程定一条分流规则，哪个进程走哪条线，自己说了算。

有米是有米IP旗下的 Windows 工具，官方介绍为永久免费、核心开源。先说清楚三点：它只支持 Windows，没有 macOS 版和手机版；软件本身不带线路，线路要另外通过正规渠道获取；最新版本是 20221029ex，2022 年 10 月 29 日发布的，之后官网没有再更新，功能现在还能用，新系统、新游戏的兼容性要自己实测。支持的代理类型不少：HTTP、HTTPS、SOCKS5、Shadowsocks、ShadowsocksR、Trojan、VPN（IKEv2、SSTP），还有代理加速隧道。

![图片[1]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117161506347-640x1024.webp/59pk)

## 先装好它

开始之前准备三样东西：一台 Windows 电脑；代理线路的四件套——地址、端口、账号、密码，缺一不可；管理员权限。线路从哪里来、共享节点和独立节点有什么区别，可以先看看站里这两篇：[SOCKS5代理IP从哪里来](https://www.59pk.net/79.html)、[共享节点和独立节点的区别](https://www.59pk.net/82.html)。另外先退出电脑上其他代理软件、加速器，别同时开着 SSTap、Proxifier 这类同类工具。

1. 打开官网 youmiip.com，下载安装包，认准官网，别从不明下载站下。
2. 右键安装包，选“以管理员身份运行”，一路点“下一步”，安装路径保持默认就行。
3. 安装中途 Windows 会弹驱动安装提示，这是进程捕获驱动和虚拟硬件驱动，点“安装”。这两样必须允许，不然有米抓不到进程、分不了 IP。
4. 装完后桌面图标同样右键“以管理员身份运行”。

## 把线路加进来

有米的主界面是个经典 Windows 桌面程序，上面是菜单栏，中间是进程列表，下面是状态栏。先认三个菜单，整篇教程都在这三个菜单里打转：功能(W)→全局设置(S) 管进程，代理(P)→代理管理(S) 管线路，代理(P)→域名系统(N) 管域名解析。

点“代理(P)”→“代理管理(S)”，线路就从这里进：

1. 直接粘贴线路，有米会自动识别格式，把地址、端口、账号、密码拆出来；也可以一项一项手动填。
2. 线路多的时候用批量添加：订阅链接、Base64 订阅文本、多种格式的批量文本，一次导多条。
3. 选中线路点检测，测 ping 和丢包率，无效的线路会标出来。也可以一键选中全部有效或全部无效的，再把无效的、重复的删掉。
4. 点“确定”保存，线路就进列表了。

![图片[2]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117161618481.png/59pk)

上图就是代理管理里的批量添加：右击空白处点“添加”，线路信息按格式粘贴进去，点确定。图里的线路信息已经打码，自己填的时候按你那条线的四件套写。

地址、端口、账号、密码四项有一个错，检测就过不了。先核对一遍再怀疑线路本身；换一条线路再测一次，是最快的排查办法。

## 告诉有米你要代理谁

点“功能(W)”→“全局设置(S)”，把要代理的游戏或模拟器加进来：可以直接把 exe 拖进去，也可以从列表里选。列表里出现这个进程后，双击它打开“编辑进程”，能改分配策略、是否代理子进程、是否限速，改完点“确定”保存。

![图片[3]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117161639217.png/59pk)

上图左边是功能菜单里的全局设置，右边是全局设置框，进程拖进来就出现在列表里，分配策略那一列就是给这个进程定分流办法的地方。

只加进来的进程才会被代理，没加进来的程序继续走本地网络直连，互不影响。浏览器、下载工具这些没加进来的，速度一点不受影响。这就是有米和整机接管类工具最大的区别。

## 选一种分 IP 的办法

分配策略定在进程上，决定这个进程用哪条线路。五种最常用的：

![图片[4]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117161757330.webp/59pk)


| 策略 | 怎么分 | 适合谁 |
| --- | --- | --- |
| 随机分配 | 每次开进程，随机挑一条可用线路 | 图个方便，不挑线路时用 |
| 均衡分配 | 按顺序轮着分，线路用量大致平均 | 多进程分摊，不想某条线过载 |
| 独占 | 一条线路只给这一个进程，别人抢不走 | 单进程单 IP，最稳的用法 |
| 绑模拟器 | 模拟器窗口编号绑定固定 IP，重启不变 | 模拟器多开，一窗一 IP 必选 |
| 绑定窗口标题 | 按窗口标题认进程，标题对上才代理 | 同名多窗口，靠标题区分时用 |

怎么选很简单：只玩一个游戏就选“独占”，一条线只给它，最稳；几个进程分摊几条线就选“均衡分配”；模拟器多开、一窗一 IP 就选“绑模拟器”，再按下面那节把线路和窗口序号绑死；不知道选哪个，先选“随机分配”跑起来，能玩、延迟正常就是对的。另外还有“自定”和“自定2”，是给有开发能力的用户留的，一般用户不用碰。

## 打开游戏，它就开始工作了

进程捕获默认就是开着的，初次使用不用手动打开。打开游戏或模拟器，进程出现在主界面列表里，后面显示分到的代理 IP 和端口。核对一下：IP 和端口对不对得上你配的那条线；再进游戏确认能登录、延迟正常。

![图片[5]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117161928439.png/59pk)

上图是主界面，进程名、PID、分到的代理 IP、流量、地理位置、代理时长都在一行里。图里的 IP 和 MAC 已经打码，你自己的界面上这里会显示真实值。

想确认出口 IP 到底变没变，在模拟器里打开 ip138.com 查一下，显示的地址和你配的线路一致，就是通了：

![图片[6]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117161942645-1024x899.png/59pk)

上图上面是主界面，两个模拟器进程都已经分到了线路；下面是模拟器里的浏览器在 ip138.com 上查到的出口 IP。

如果进程后面没有 IP、还是走本地，先看这三处：进程捕获是不是开着的（托盘图标灰了就是停了）；进程有没有加进全局设置；分配策略有没有匹配上可用的线路。还有一种可能：没匹配到代理时，流量会重定向到本地，看起来就像没代理一样。三处都对，基本就能通。

不用的时候直接关游戏或模拟器就行；想彻底停掉，点停止捕获或退出有米，流量恢复直连，不用改任何系统设置。

## 模拟器多开：让每个窗口的 IP 固定下来

模拟器多开最要紧的是：重启任意一个窗口之后，窗口序号对应的 IP 永久不变，不会串。做法分两步：

第一步，给进程定策略。点“功能(W)”→“全局设置(S)”，鼠标左键双击雷电进程打开“编辑进程”，把“分配策略”改为“绑模拟器”，点“确定”保存。

第二步，给线路加标识。点“代理(P)”→“代理管理(S)”，选中要绑定的代理 IP，鼠标右键菜单→“编辑”，在“允许使用的进程”里（原来写着 `ALLNAME;ALLMD5;`），在后面追加该模拟器的绑定标识，保存：

![图片[7]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117162026980.png/59pk)

上图下面就是编辑代理的框，`ALLNAME;ALLMD5;` 后面就是追加绑定标识的地方；上面列表里“可分配”那一列填的是这条线路能开几个窗口，开几个窗口就写几个。图里的线路信息已经打码。

绑好之后重启任意模拟器窗口，序号对应的 IP 不变。雷电、MuMu、蓝碟模拟器都支持这样绑。

## 国外游戏登不上，多半是域名解析

已经用了国外线路，游戏还是登不上、国外网页打不开，多半是域名解析没走代理。模拟器里的浏览器打开 google.com，是这个样子：

![图片[8]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117162122690.png/59pk)

解决办法在域名系统里。点“代理(P)”→“域名系统(N)”，先把“域名解析”设为“全局转发”（下图红箭头指的地方），首选 DNS、备用 DNS 照图里这样填就行：

![图片[9]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117162201938.png/59pk)

再把“代理类型”改成 SOCKS5，“代理 IP”填一条非大陆的代理 IP，端口、账号、密码按你那条线路的信息填，点“确定”：

![图片[10]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117162240211.png/59pk)

设好之后，主界面底部会出现一条红色状态条，这就说明 DNS 代理生效了：

![图片[11]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117162312409.png/59pk)

再打开浏览器，google.com 就能正常打开了：

![图片[12]-天天向上](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261117162337356.png/59pk)

域名系统里还有几处平时用得到：首选 DNS 和备用 DNS 都支持走代理；域名黑白名单支持通配符，可以指定哪些域名走代理、哪些直连；域名被污染时可以换基于 TCP 的解析试试；DNS 缓存可以一键复制成 hosts 格式，方便排查。平时不用动这些，只有遇到打不开网页、解析慢、国外游戏登不上时再来这里改。

## 还有几处顺手可以调的

- 子进程：可以个别设置某个进程的子进程要不要代理、子进程用不用不同的代理 IP；也可以把某个子进程设为不代理，让它直连。
- 进程限速：给单个进程限速，不想某个进程占满带宽时用。
- 超前分配：打开后，有米可以在被代理的进程打开之前就先把线路分配好，进程一启动就有 IP，不用等。
- 虚拟硬件：有米还能给被代理的进程一套虚拟的硬件信息（虚拟注册表、虚拟硬件特征），主要用来应对部分游戏的检测，一般用户不用动，保持默认就行。

## 如果遇到问题

退出有米之后断网、应用没网，是有米退出时偶尔会留下网络设置没恢复。用“附加功能”里的“网络重置修复”修一次，再重启电脑，一般就好了。以后退出时留意提示，不要直接杀进程。

驱动加载失败、进程捕获不到，先右键“以管理员身份运行”；还不行就重启电脑再试；再不行就重装一次有米，让驱动重新装一遍。也不要同时开着其他进程代理工具，驱动层面会互相干扰。

至于有米、SSTap、Proxifier 该用哪个：有米按进程分配，擅长模拟器多开、一窗一 IP；SSTap 整机接管，按模式分流，适合只加速一个游戏、不想逐个配进程；Proxifier 按进程和域名精细定规则，适合只让指定软件走代理、其余全部直连。三者不要同时开着接管同一台机器。

## 写在最后

配好之后，正常用法就是：有米开着，打开游戏或模拟器，列表里看到进程和分到的 IP，就行了。线路要换的时候去代理管理里加新的、把旧的删掉；模拟器要加窗口的时候，按绑模拟器那两步再绑一条。动态 IP 和静态 IP 怎么选、代理请求超时了怎么查，可以看看站里这两篇：[动态IP还是静态IP？先看业务节奏，再挑地址类型](https://www.59pk.net/76.html)、[HTTP代理请求超时排查指南](https://www.59pk.net/91.html)。
