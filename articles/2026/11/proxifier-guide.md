有些程序根本没有代理设置这一项：邮件客户端、数据库工具、某些游戏和行业软件，打开设置翻到底也找不到代理那一栏。Proxifier 就是为这种情况准备的：它装在电脑上，接管所有出站的 TCP 连接，按你定的规则决定每条连接是直连、拦截，还是走代理。程序本身不用改，照常打开，流量已经按你的规则走了。

这篇是 Windows 版的完整用法，以 v4.14 为例。macOS 也有对应版本，菜单和步骤基本一样。

## 开始之前，先准备好这两样

第一样是代理服务器的信息：地址、端口、协议、认证方式。这些按你所用代理服务的说明来填，不同服务的端口和认证方式不一样，不要凭印象猜。[申请代理 IP 的时候就要把类型想清楚](https://www.59pk.net/221.html)，类型定了，协议和端口才定得下来。

第二样是 Proxifier 本身。只从官网 proxifier.com 下载，有 Windows 标准版和便携版，Windows 7 到 11 都能装，安装需要管理员权限。31 天试用期内功能没有限制，到期后是一次性付费的永久授权。以下截图是中文界面，正版英文界面的菜单位置相同。

## 第一步：把代理服务器加进去

装好打开 Proxifier，点菜单栏的“配置文件”，再点“代理服务器”。

![点“配置文件”菜单，打开“代理服务器”](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144430171.webp/59pk)

在弹出的对话框里点“添加”，填地址和端口，再选协议：SOCKS 5 还是 HTTPS，看你的代理服务支持哪一种，也看业务要求。需要账号密码认证的，把“认证”下的“启用”勾上，填好用户名和密码。填完点“确定”。

![“代理服务器”对话框，点“添加”](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144437882.webp/59pk)
![填代理地址、端口、协议和认证信息](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144445414.webp/59pk)

加完先别急着用，选中刚加好的这条代理，点“检查”。弹出的“代理检查器”里点“开始测试”，会一行一行显示测试信息。绿色代表测试通过，红色代表没通过：先对一下端口和协议是不是跟代理服务给的一致，认证的账号密码有没有填错，白名单方式的有没有把本机出口 IP 加进白名单。

![选中刚加好的代理，点“检查”](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144449354.webp/59pk)
![“代理检查器”测试通过](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144455249.webp/59pk)

测试通过之后，[去查一下出口 IP](https://www.59pk.net/ipcheck)，确认流量确实走了代理，再往下配规则。

## 第二步：定规则，谁走代理谁直连

代理加好了还不等于生效，Proxifier 靠规则决定每条连接的去向。点“配置文件”→“代理规则”，打开规则对话框。

![点“配置文件”菜单，打开“代理规则”](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144504635.webp/59pk)

想让所有程序都走代理，就把 Default 这一行的“动作”改成你刚加好的代理。这一改就是全局代理：电脑上所有出站连接都走这条代理。

![把 Default 的动作改成代理](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144511469.webp/59pk)

只想让某一个程序走代理，其他程序照常直连，就点“添加”新建一条规则。

![点“添加”，新建一条规则](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144515183.webp/59pk)

名字随便取，比如“远程桌面”；点“浏览”，找到那个程序，或者填它在任务管理器里的进程名；目标主机和目标端口保持默认；动作选你配好的代理，点“确定”。

![新建规则：填名字、选程序、选动作](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144527930.webp/59pk)

如果只想代理这一个程序，记得把 localhost 和 Default 这两行留在 Direct 上，不要改。规则是从上往下匹配的，第一条命中的先生效，所以特定程序的规则要放在 Default 上面。

![新建的规则出现在规则列表里](https://oss.file.59pk.net/wp-content/uploads/2026/11/20261118144534602.webp/59pk)

这一步的思路和[有米网游加速器](https://www.59pk.net/196.html)是一个路子：按进程走代理，一个进程一条线。只不过有米是进程代理工具，Proxifier 是在系统层面接管流量，[SSTap](https://www.59pk.net/183.html) 也是装在电脑上走代理的客户端，三者的形态不同，解决的问题有重叠。[模拟器多开、一个窗口一个 IP 的场景](https://www.59pk.net/135.html)，同样可以用“指定进程”这条规则去配。

## 代理链和 DNS，两个常用的进阶设置

一条代理不够用的时候，可以把多条代理串成代理链：同一条链里能混用不同协议，配置界面直接拖拽就能排顺序。链路越长速度越慢，够用就行，不用贪多。

DNS 另外注意一下：Proxifier 支持系统 DNS 和代理 DNS 两种方式。走代理的话，域名解析也通过代理做，配好之后不容易出现解析泄漏；用系统 DNS 解析，域名这一步还是走本地。看你的业务需不需要把解析也藏起来，再决定用哪一种。通配符排除列表可以把某些域名排除在代理 DNS 之外。

代理服务器那一栏里还支持故障转移和负载均衡：一条代理挂了自动切到备用，或者多条代理分着用。

## 连不上，先查这几处

测试一片红，先看端口和协议：填的端口是不是代理服务给你的那个，协议是不是服务支持的那个。长效和隧道、账密和白名单，端口经常不一样，以服务说明为准。

认证失败，先看账号密码，再看白名单：白名单方式认的是出口 IP，本机出口变了就得重新加。

某个程序死活不走代理，先看规则顺序：特定程序的规则有没有放在 Default 上面；再看进程名：填的是不是任务管理器里实际跑起来的那个进程名，路径指错了就匹配不上。

配好之后还是觉得不对，[直接测一下出口 IP 和有没有 DNS 泄漏](https://www.59pk.net/ipcheck)，看流量到底从哪出去，比猜快得多。

Proxifier 的核心就是这两样：代理服务器是“走哪条路”，代理规则是“谁走这条路”。路加对了，规则排对了，没有代理设置的程序也能老老实实走代理。
