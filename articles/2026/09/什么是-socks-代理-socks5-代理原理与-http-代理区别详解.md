SOCKS 代理是工作在会话层的通用代理协议，只转发原始数据包、不解析应用层内容，SOCKS5 在 SOCKS4 基础上增加了 UDP 支持、身份认证和远程域名解析。

## 一、SOCKS 代理是什么

SOCKS（Socket Secure，安全套接字代理），是一套**工作在 OSI 模型会话层**的网络代理协议，简单来说：它是一个中转隧道，把客户端的网络请求转发给目标服务器，再把服务器返回的数据传回客户端。

和 HTTP 代理不一样，SOCKS**不解析应用层协议内容**，不会去解读你传输的是网页、文件、视频还是 API 请求，只单纯转发原始网络数据包。这也是 SOCKS 最大的特点：**通用性极强**，几乎可以代理所有 TCP/UDP 类网络程序。

SOCKS 分为两个主流版本：SOCKS4 和 SOCKS5，现在大家日常使用的基本都是 SOCKS5。

## 二、SOCKS4 与 SOCKS5 核心区别

### 1.SOCKS4

仅支持 TCP 连接；**不支持 UDP**；不支持身份验证；只能处理 IPv4 地址。 功能简单，现在已经基本淘汰，极少场景使用。

### 2.SOCKS5

是目前主流版本，新增大量能力：

- 同时支持 **TCP + UDP** 流量转发（比如游戏、DNS、视频流）
- 支持账号密码认证，也支持无密码匿名连接
- 支持 IPv4、IPv6 域名解析
- 支持远程域名解析（远端解析，避免本地 DNS 泄露）

> 一句话总结：SOCKS4 只能转发 TCP，SOCKS5 能转发 TCP+UDP，支持认证、域名解析，实用性强很多。

## 三、SOCKS 代理的工作原理

SOCKS 代理的工作流程，一共 4 步：

1. **客户端握手**：你的软件（浏览器、工具、APP）先和 SOCKS 代理服务器建立连接，发送请求，告诉代理你要访问哪个目标地址和端口。
2. **代理服务器校验**：如果 SOCKS5 设置了账号密码，这一步会做身份验证；无密码代理直接跳过。
3. **建立远端连接**：代理服务器代替你的设备，去连接目标网站 / 服务。
4. **双向数据中转**：连接成功后，代理就变成 “管道”，双向转发客户端和目标服务器之间所有数据包。

整个过程，SOCKS 代理**只转发数据包，不会修改 HTTP 请求头**。不像 HTTP 代理会添加`X-Forwarded-For`这类请求头。

## 四、SOCKS5 代理分类（按使用场景）

### 1.静态 SOCKS5（固定 IP）

代理 IP 长期不变，IP 归属固定。适合爬虫、账号维护、业务测试，稳定性高，IP 不容易频繁变动；缺点是价格更高，数量有限。

### 2.动态 SOCKS5（短效 / 短效住宅 IP）

每次连接或者每隔一段时间自动切换 IP。大量爬虫、数据采集场景最常用，IP 池大，可以高频换 IP。分为机房 IP、住宅 IP（家庭宽带 IP）。

### 3.临时一次性 SOCKS5

每一次网络请求就更换全新 IP，单次用完即弃，适合高并发采集，成本较高。

## 五、SOCKS 代理 VS HTTP 代理，核心差异

很多人会混淆 SOCKS5 和 HTTP 代理，这里简单区分：

- **SOCKS5**：会话层协议，**通用隧道**。支持浏览器、SSH、游戏、各类客户端软件，不解析 http 内容；可以代理 UDP；匿名度更高。
- **HTTP 代理**：应用层协议，**专门处理 HTTP/HTTPS 网页请求**。只能代理网页流量，会解析 HTTP 请求头，UDP 不支持。

举例子：

- 浏览器上网、访问网页：SOCKS5、HTTP 代理都能用。
- 游戏、SSH 连接、数据库连接、各类客户端工具：**只能用 SOCKS5，HTTP 代理无法支持**。

> HTTPS 网页：SOCKS5 只是转发隧道，不会解密 HTTPS 流量；HTTP 代理在处理 HTTPS 时用 CONNECT 方法建立隧道。

## 六、SOCKS 代理的匿名性

SOCKS 本身只是转发通道，匿名等级取决于代理服务器本身：

1. **普通 SOCKS**：目标服务器只能看到代理服务器 IP，看不到你本机真实 IP；但代理服务商后台可以记录你的原始 IP 和访问日志。
2. 注意：SOCKS**不会隐藏 DNS 请求**（默认本地 DNS）。如果不开启远端域名解析，你的本地 DNS 查询会直接向外发送，造成 DNS 泄露。这是很多新手踩坑点，SOCKS 客户端一定要打开「远端解析 / 远程 DNS」。

> 重点：SOCKS ≠ 绝对匿名，只是隐藏本机 IP；代理服务商可以记录流量，不要用于违规用途。

## 七、SOCKS 代理的常见使用场景

1. 各类客户端工具：SSH、数据库连接、网盘、各类 API 工具
2. 爬虫、数据采集：SOCKS5 是爬虫最常用协议，很多爬虫框架原生支持 socks5
3. 游戏联机：UDP 转发能力，适配部分游戏流量
4. 浏览器全局代理：搭配 SwitchyOmega 等插件，浏览器走 SOCKS 隧道
5. 软件调试：给各类没有内置 HTTP 代理选项的程序配置网络中转

## 八、SOCKS 代理的优缺点

|  |  |
| --- | --- |
| **优点** | **缺点** |
| 通用性强，几乎支持所有 TCP/UDP 软件，不限于网页 | 部分软件不支持 SOCKS 协议，只能用 HTTP 代理 |
| 协议简单，开销小，转发速度更快，性能损耗低 | 默认情况下 DNS 请求不走代理，容易 DNS 泄露，需要手动开启远程解析 |
| 支持 UDP 流量，HTTP 代理做不到 | 很多免费 SOCKS 代理不稳定、存活时间短，存在盗号、流量劫持风险 |
| 不篡改应用层数据，不会修改 http header | SOCKS 代理本身不做加密（原生 SOCKS5 明文传输），如果需要加密隧道，一般搭配其他加密层。 |

## 九、常见问题

**Q：SOCKS5 是加密代理吗？**  
A：不是。原生 SOCKS5 传输是明文，只负责转发数据包、本身没有加密；市面上很多加密代理底层虽然使用 SOCKS5，但额外套了一层加密。

**Q：用了 SOCKS 代理就能隐藏所有信息吗？**  
A：不能。它只能隐藏你的本机 IP；如果 Cookie、浏览器指纹、账号信息不变，网站依然可以识别你。

**Q：SOCKS4 支持 UDP 吗？**  
A：不支持。SOCKS4 仅支持 TCP，UDP 是 SOCKS5 新增的功能。

## 十、合规提醒

SOCKS 代理本身只是网络中转技术，**使用行为必须遵守《网络安全法》等国内法律法规**。禁止利用代理访问境外非法网站、网络爬虫恶意攻击、批量注册账号、刷量等违规操作，违规使用会承担对应的法律责任。
